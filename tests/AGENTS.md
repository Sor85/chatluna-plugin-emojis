# tests 说明

适用范围：`tests/`。同时遵守根 `AGENTS.md`；服务契约见 `src/AGENTS.md`。

- 测试使用小型合成元数据与临时目录，不下载真实上游、不访问用户数据。
- 覆盖多码点与变体选择符、正反向查找、最新组合、非法图片地址、缓存冷启动、条件请求、源切换、损坏缓存、失败回退、并发合并、大小上限和取消。
- 命令验证权限边界及单次图片回复；无前缀触发覆盖默认关闭、显式启用、完整消息匹配及复用命令执行。
- 结构守卫检查每份子目录 `AGENTS.md` 均登记、登记路径存在，分发入口完整且不含客户端页面。
- 配置测试检查每个字段在表单实际渲染的 Schema 上都有中文 label 和描述：`checked()` 会包一层 transform，表单只渲染内层，挂在外层的 meta 不显示。
